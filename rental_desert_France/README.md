# rental_desert_France (R)

- rental deserts in France, idea from the JCHS *Rental Deserts* paper (Airgood-Obrycki, Maaoui, Wedeen 2024)
- IRIS level, INSEE census 2021; rental desert = under 20% rental
- divergence index for the top 100 urban units; income / building-age segregation; SRU law regression
- final: `France_FillBlanks.Rmd` (tables), `France_Figures (1).Rmd` (figures)
- `1_`, `2_` R scripts = adapted from the JCHS scripts
- other Rmd = earlier tries
