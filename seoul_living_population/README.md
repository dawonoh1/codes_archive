# seoul_living_population (Python)

- master's thesis, 2018–2019, Seoul living population (생활인구), 집계구 level
- `월별 생활인구 데이터 총계_MS.py`: load a month of files, UTF-8/CP949 encoding, `*` (≤3 people) → 0, split 집계구 code, 20–39 young / young women, weekday vs weekend, pivots
- `생활인구 연령별구분 19년도.py`: same for 2019, by age group
